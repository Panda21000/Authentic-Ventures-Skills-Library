    Plain English — the task, not the tool name. It reads which stage of the deal cycle you're in and tells you what else that workflow needs, not just which file to install.

    New here? Three things worth knowing.

    A skill is a markdown file telling Claude how to do one job well — a method, not software. An MCP server is separate software that gives Claude live data. Skills are free and instant; MCP servers usually need a key or a subscription.

    1. Filter to Tier A plus no key, no account — that's everything you can use in the next five minutes.
    2. Hit Install on a row for the exact command, or the ZIP for the Claude web app.
    3. Don't enable everything. Claude picks skills by matching your request against their descriptions, so 100+ overlapping skills makes it worse, not better. Start with 10.
